# PhysioEDA: Electrodermal Activity Analysis for PhysioExperiment Objects

Provides electrodermal activity (EDA / skin conductance) analysis
functions for PhysioExperiment objects. Includes preprocessing
(filtering, downsampling), artifact detection and correction,
tonic/phasic decomposition (highpass, median, CDA, cvxEDA), SCR peak
detection, feature extraction, data transformations, signal quality
assessment, visualization, and event-related SCR analysis.
